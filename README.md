# XIV Mini Util

FFXIV用のDalamudプラグインです。

マテリア精製・装着マテリア回収と分解の操作支援、NPC販売場所の検索、外部マーケット最安値確認、日課チェックリスト、シャキ通知、キャラ選択画面の保存エモート再生を提供します。

## 機能

- マテリア精製の自動実行とオン・オフ
- 装備に装着されたマテリアの右クリック連続回収
- 分解の条件設定と警告ダイアログ
- アイテム販売場所の検索（マップピン・テレポ）
- Universalis APIによるマーケット最安値確認
- 日課チェックリスト（Daily/Weekly、通知設定）
- コンテンツ突入確認時のWindows通知音
- キャラ選択画面でのキャラ別保存エモート再生
- キャラ選択画面の背景変更（収録背景の選択、背景ごとに調整した時刻・天候を適用、構図の保存/再現、1クリック確認、失敗時は安全側で自動停止）
- 潜水艦の複数キャラ横断・帰投サマリーとDiscord通知

## インストール（カスタムプラグイン）

現在の配布版は次の通りです。

- Stable: `0.4.0` / Dalamud API 15
- Testing: `0.4.0` / Dalamud API 15

`0.3.0 / API14` は過去リリースとして残しています。

1. `pluginmaster.json` をRawで公開します。  
   例: `https://raw.githubusercontent.com/zlatan-mt/XIV-Mini-Util/main/pluginmaster.json`

2. Dalamud の「Custom Plugin Repositories」にURLを追加します。

3. `XivMiniUtil.zip` をGitHub Releasesに添付して配布します。

配布手順の詳細は `docs/release/custom-plugin-distribution.md` を参照してください。

## 使い方（基本）

- `/xivminiutil` または `/xmu` でメインウィンドウを開きます。
- `/xivminiutil config` または `/xmu config` で設定タブを開きます。
- `/xivminiutil version` または `/xmu version` で、ゲーム内で読み込まれているDLLのパスとバージョン情報を確認できます。
- `/xivminiutil help` または `/xmu help` で使用できるコマンドを確認できます。

## 販売場所検索の使い方

1. アイテムを右クリックして「販売場所を検索」を選びます。

2. 検索結果が複数ある場合、一覧ウィンドウが開きます。  
   上位10件のみ表示されます。

3. 行をクリックするとマップピンが刺さります。  
   テレポボタンは上位10件のみ表示されます。

4. 設定タブからショップデータの再構築と進捗確認ができます。

## 外部マーケット検索の使い方

1. アイテムを右クリックして「Universalisで最安値確認」を選びます。

2. 現在いるDC内の最安出品がチャットに表示されます。表示される価格は税抜の単価です。

3. 「設定」タブの「ショップ検索」から、安値3位までの表示とデータセンター外検索を切り替えられます。

## 装着マテリア回収の使い方

1. マテリアが装着された装備をインベントリ、アーマリーチェスト、またはマテリア装着画面で右クリックし、「装着マテリアをすべて回収」を選びます。

2. 選択した時点で回収キューへ追加されます。回収中に別の装備を同じ操作で追加すると、登録順に順次回収します。進捗はホームタブに表示されます。

3. 回収中はマテリア精製を一時停止します。精製UI、回収確認ダイアログ、エリア移動など安全な判定ができない状態では停止します。

ホームタブの一括回収は通常所持品（Inventory1〜Inventory4）のみを対象にし、候補数・マテリア合計・除外理由を確認してから開始します。右クリックの個別追加は確認なしでFIFOキューへ追加されます。

自動開始やキューの永続化は行いません。ゲーム内の回収結果と確認ダイアログの動作は、使用中のパッチで確認してから利用してください。

## 設定のポイント

- 「検索時/マップピン時に自動テレポ」をONにすると、  
  最寄りのエーテライトへ自動テレポします。
- 「ショップデータを再構築」からキャッシュを手動更新できます。
- 「チェックリスト」タブで日課項目を完了・リセットできます。通知時刻などは「設定」タブの「チェックリスト」で設定します。
- 「設定」タブの「シャキ通知」から通知音と再生時間を設定できます。
- 「設定」タブの「キャラ選択」から、ログイン中に実行したエモートの記録とキャラ選択画面での再生を設定できます。
- キャラ選択背景の通常設定と1クリック確認は「設定」タブの「ログイン背景」にあります。キャラ選択画面では、マウスで調整後に「現在の構図を保存」を押すと、次回の初期構図として再現されます。
- 「ログイン待機中にログイン先エリアを事前読み込みする」は背景画像の任意差し替えではなく、ログイン先テリトリーのLayout事前ロードです。

## 開発者向け（必要な場合のみ）

```powershell
dotnet build projects/XIV-Mini-Util/XivMiniUtil.csproj -c Release
```

現在のソースツリーはStable API15版のビルド用です。旧Stable API14版を再生成する場合は、`v0.3.0` タグなどAPI14設定が残るソースからビルドします。

## 注意事項

- Stable / Testing ともに Dalamud API 15 / .NET 10 向けです。
- 自動操作は自己責任で使用してください。
