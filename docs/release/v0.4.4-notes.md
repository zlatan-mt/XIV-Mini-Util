# XIV Mini Util v0.4.4

キャラ選択画面で背景変更を使用しているとき、ログイン確認や混雑待ちの間も背景を明るいまま表示するよう改善しました。

- 確認メッセージやキャンセル操作を維持し、対象ダイアログの背景の暗幕を除きます。
- 保存エモートの再生・停止時に現在のキャラクターを確認し直し、キャラ切り替え前の参照へ操作しないよう修正しました。
- 「FRU クリア後ステージ」背景で、キャラクターの配置確認後にカメラ焦点の水平位置を同期します。

Dalamud API 15 / .NET 10向けです。Stable / Testingは同じバージョンを使用します。既存の通常版は、プラグインインストーラーから更新できます。

暗くなる現象の解消はDev版で利用者が確認しています。FRU背景の初回表示やちらつき全般については、引き続き確認が必要です。Dev版の自動診断・自動クリップボードコピーは通常版では動作しません。

Dev版から移行する場合は、設定の保存先が別になるため、[設定のバックアップと切り替え手順](https://github.com/zlatan-mt/XIV-Mini-Util/blob/v0.4.4/docs/release/custom-plugin-distribution.md#dev版から通常版への切り替え)を参照してください。
